## 1. 要解决的问题（学校实地观察）

| 现象 | 根因 |
|------|------|
| 刚上课全班持续吵闹，等级条却到不了「一般」 | 持续聊天 RMS 本就不高（约 0.02~0.04），卡在阈值下；也可能有麦克风 AGC 压低增益（**需数据确认**） |
| 打喷嚏/咳嗽被误记成「吵闹」 | 一个 100ms 块内的瞬态让整块 RMS 冲过阈值；RMS 对瞬态天然敏感 |

核心结论：判断从「现在有多大声」→「这段时间持续有多吵」；**计数与显示分离**；**检测（事件）与等级（显示）分离**。

## 2. V2 音量检测算法

### 2.1 信号链总览

```
麦克风 WaveInEvent（100ms/块, 44100Hz 16bit mono）——后台音频线程
   ↓ 每块计算 RawRMS + Peak
EMA 平滑：smooth = 0.2×raw + 0.8×smooth（τ≈500ms）
   ↓
迟滞分级：smooth → Level{Quiet,Good,Normal,Noisy}（升用名义阈值，降×0.8）
   ↓
持续判定状态机：等级连续保持 ≥NoisySustainSeconds → 产生「持续事件」(Normal/Noisy)
   ↓ 每段至多 1 次事件；段内升级(一般→吵闹)可再产 1 次
事件驱动计数：NoiseCounter 应用 升级/冷却/保护 规则 → 更新计数/显示
```

- **①② 线程归属**：EMA/迟滞/持续判定全部在 `DecibelMeterService.OnDataAvailable`（音频采样线程）执行，**不依赖任何 UI Timer**。UI 1 秒定时器只管时钟/日期/课程/倒计时，与音频 10Hz 采样无关——二者分离，互不影响。
- 显示路径走 smooth + Level（咳嗽只闪一下、不打爆）；计数路径只由「持续事件」驱动。

### 2.2 纯类抽取（为单元测试）

算法抽成两个**纯类**（只依赖 System，不依赖 ClassIsland/Avalonia/NAudio），放在插件项目 `NoiseDetection/` 下；测试项目直接以源文件方式编译它们，不引入额外 DLL（避免影响 cipx 打包）。

**`NoiseEventDetector`**（检测，纯算法）
- 配置：四个阈值、`SmoothAlpha`(0.2)、`HysteresisFactor`(0.8)、`SustainSeconds`、`NoisyRatioThreshold`(0.5)、`GraceSeconds`(1.0)
- 状态：`_smooth`、`_level`、`_episodeActive/_episodeNormalSeconds/_episodeNoisySeconds/_episodeFired/_graceLeft`（持续段）
- `Process(rawRms, dt) → SampleResult{ Level, LevelChanged, EventFired, EventLevel, SmoothedRms }`
- 逻辑：
  - 进可计等级（Normal/Noisy）→ 开段，**分别累计段内「一般」「吵闹」时长**；**累计 ≥ SustainSeconds 且本段未触发 → 产一次事件**，事件归属按段内占比判定：吵闹占比 ≥ `NoisyRatioThreshold`(0.5) → 吵闹，否则一般（**触发即定格**）
  - **段内一般↔吵闹来回波动**：不重置计时、不重触发，每段只记一次（归属只看触发那一刻为止的占比）
  - 回落到不可计等级（Good/Quiet）→ 进入宽限期（`GraceSeconds`），宽限期内短暂停顿不断段、累计不清零；超过宽限期段才结束
- 迟滞：升用名义阈值，降 ×0.8（Schmitt 触发）

**`NoiseCounter`**（计数规则，纯算法）
- 配置：`CooldownSeconds`(60) —— 一般、吵闹**各自独立冷却**，互不阻挡
- 状态：`_inBreak`、`_lastNormalTime`、`_lastNoisyTime`、`NormalCount/NoisyCount`
- `OnEvent(level, now, isProtected) → CountDecision{None, CountNormal, CountNoisy}`
  - 课间或保护期 → None
  - Noisy 事件：走吵闹自身冷却，通过才 `CountNoisy`
  - Normal 事件：走一般自身冷却，通过才 `CountNormal`
- `StartNewClass()` 重置计数；`SetBreak(bool)` 切换课间
- 设计动机（2026-08 CSV 实测）：旧版 30s 升级窗口 + 共用冷却，导致「一般」恒为 0；新版分开冷却让「一般」能稳定记上；段内归属（一般还是吵闹）已由探测器按占比判定，计数层只管冷却/保护，不再有升级改记

### 2.3 计数规则（已定：持续一段算一次）

```
OnNoiseEventRaised(level):   // level = Normal(一般) 或 Noisy(吵闹,含嘈杂)
    decision = _counter.OnEvent(level, now, isProtected)
    // isProtected = SkipFirst3Min && (NowVirtual - classStart) < SkipFirstMinutes×60
    按 decision 刷新计数显示 / 课间总结
```

### 2.4 参数表

| 参数 | 默认值 | 是否设置项 |
|------|--------|-----------|
| EMA α | 0.2（τ≈500ms） | 否（常量） |
| 迟滞系数 | 0.8 | 否（常量） |
| **持续判定时长 NoisySustainSeconds** | **1.5s** | **是（新增）**，初始实验值，最终由 CSV 实测确定 |
| **吵闹占比阈值 NoisyRatioThreshold** | **0.5** | 否（常量，段内吵闹占比 ≥ 0.5 记吵闹，否则记一般） |
| 噪音阈值 安静/良好/一般/吵闹 | 0.005/0.015/0.04/0.08 | 是（现有） |
| 冷却时间 NoisyCooldownSeconds | 60s | 是（现有，补控件） |
| 保护开关 / 保护时长 SkipFirstMinutes | 开 / 3min | 是（新增时长，默认 3） |
| 30s 升级窗口 | ~~30s~~ | **已移除**（占比法替代升级改记） |
| **调试日志开关 EnableNoiseDebugLog** | **关** | **是（新增）** |

### 2.5 边界情况
1. 保护期内出现持续段：事件产生但被保护规则丢弃；该段不再计数，**回落再起才算下一段**。
2. 持续吵闹中过冷却：段内不重触发，下一段受冷却挡住。
3. 一般↔吵闹来回波动：计时不重置、不重触发，触发时按段内占比归属（吵闹 ≥ 50% 记吵闹，否则记一般），每段只记 1 次。
4. 打喷嚏 0.3s：达不到持续时长 → 无事件 ✅。
5. 全班持续聊天 5min：≥1.5s 记 1 次；不掉段不重记 → **5min ≈ 1 次**。
6. 吵闹→一般回落：不重复计数；掉到良好/安静才算段结束。

### 2.6 调试日志（设置项开关）
- 开关：`EnableNoiseDebugLog`（默认关，设置页勾选开启）。
- 输出：`Plugin.ConfigFolder/NoiseDebugLog.csv`。
- 列：`时间, RawRMS, Peak, SmoothRMS, Level, Episode, EventState(无段/持续中/已触发), 保护中, 冷却剩余`。
- 目的：拿学校真实数据校准阈值、判断 AGC、定位误报。

## 3. 性能优化

| 项 | 现状 | 改法 |
|----|------|------|
| 刷新定时器 | 200ms（5Hz） | 1000ms（时间只到秒） |
| 计数触发 | 每 100ms 文本变化都跑 | 只由「持续事件」驱动（低频） |
| 显示通知 | 每块 4 个属性 10Hz 全量通知 | 仅 Level 变化 或 进度差>1 时通知 |
| UpdateNoisyDisplay | 每次全量 Clear+重建集合 | 加脏标记，内容未变不重建；保护倒计时单独 1s 刷 |
| NowVirtual | 每次 GetService 查服务 | 构造时缓存 IExactTimeService（null 容忍降级 DateTime.Now） |
| 设置保存 | 每次属性变化写盘 | 400ms 防抖定时器 |

### 二轮修订（2026-08-22，针对真机反馈 + GPT DLL 复核）

**问题与修复：**
1. **升级重新计时（P0）**：原实现段内升级会 `_episodeStart = _time`，一般→吵闹要再等一个完整持续时长，体感"怎么改都很长"。改为**升级不重置累计时长**：段内只升等级，累计可计时长保留，升级瞬间若已满足持续时长立即产更吵等级事件（供 30s 升级逻辑）。对应测试 `EscalationWithinSustainWindow_FiresSingleNoisyEvent` + `NormalThenEscalatesToNoisy`。
2. **一般不计数（P1，机制确认）**：教室说话一停，smooth 掉到阈值以下立刻断段，1.5s 累计永远攒不够。新增 **宽限期 GraceSeconds=1.0s**：掉到不可计等级后不立即断段，宽限期内短暂停顿（如说话间隙）保留累计时长；超过宽限期才断段。咳嗽/喷嚏仍不计数（累计不足）。测试：`BriefDipBelowCountable_DoesNotResetEpisode` / `LongDipBelowCountable_ResetsEpisode` / `ScatteredBriefTalk_NoCount`。
3. **dt 写死 0.1（P1）**：改为按真实音频块时长 `samples / SampleRate` 传 dt，持续判定时长在现实时间上准确。
4. **麦克风选择与实际使用混为一谈（P0，已解决）**：原实现打开失败自动换设备后会**覆盖用户设置的选择**，且运行中切换不重启。二轮修复为选择/使用分离 + 立即切换 + 显示当前使用；但用户反馈该功能反复出现"选了不显示"的困惑（v1.0.1.1 起**整个设备切换功能已移除**，固定用默认设备）。
5. 测试由 14 → 18 个，全部通过。

**真机验证注意事项：** 测试算法时先关掉"上课初期保护"、把冷却时间调短，否则刚上课 3 分钟内任何事件都会被丢弃，会误以为算法坏了。

### 四轮修订（2026-08-28，V2.1「段模式」计数改造）

> 用户拍板：**舍弃冷却 CD 式计数，改为「段模式」**；回落窗口默认 5 秒（可调 0~15），其余按设计。
> 范围仍只动算法与对应 UI，不加新功能。版本号发布时再定。

**取代的机制（V2 → V2.1）：**

| 被取代 | 新机制 |
|--------|--------|
| 持续判定（累计满即触发事件） | 段内**累计有效时长**，段**结束**（回落超窗）才结算一次 |
| 冷却 CD（NoisyCooldownSeconds） | **无冷却**。每段结算即计数，段间互不阻挡 |
| 宽限期 GraceSeconds | **回落窗口 FallWindowSeconds**（0~15s，默认 5）：回落 ≤ 窗口不断段、有效时长不清零、并成一次；超窗段才结束 |

**段模式规则：**
- 进入一般/吵闹 → 开段；段内累计「有效时长」= 真正处于一般/吵闹的时间（一般/吵闹分别累计）。
- 一般↔吵闹来回波动：不重置累计、不重触发，每段只记一次（归属看段结束时占比）。
- 回落计时：≤ 回落窗口不断段、并成一次；> 回落窗口段结束、结算一次。
- 段结束结算：有效时长 ≥ 起算底线（`SustainSeconds`，默认 **1s**，可调 0.5~5）→ 按占比归属产事件（吵闹 ≥ 50% 记吵闹，否则记一般）；不足 1s 的短段（喷嚏/咳嗽）**丢弃**。
- **实时「正在记录」提示**：段起算后按当前段内占比实时判定（一般=黄、吵闹=红），起算前/段结束后隐藏；仅计数可见且上课时段显示，让同学们知道正在记录。
- 计数层：课间、上课初期保护期内不计数，其余一律计数（无冷却）。

**RMS 阈值对数滑块：**
- 滑块值域 -3~0 ↔ 阈值 0.001~1.000（阈值 = 10^index）。教室实际阈值集中在 0.04~0.14，对数刻度在低值区才能精细拖动；拖动滑块或直接填数字，双向联动。

**实测认知（EMA 平滑副作用）：**
- EMA（α=0.2）会把短促噪音**拉长**：0.2~0.4s 的强咳嗽/喷嚏，平滑值衰减到阈值以下需约 7 块拖尾，实际「有效时长」≈ 0.5~1.2s。
- 因此 1s 起算底线能挡住**普通音量**咳嗽/喷嚏（有效 <1s），挡不住超响强音（有效 ≥1s）——用户可将起算底线调大进一步放宽。
- 单元测试取值在远离边界处验证「有效时长不足 1s 丢弃」这一语义。

**参数表变化（相对 §2.4）：**
| 参数 | 默认值 | 变化 |
|------|--------|------|
| NoisySustainSeconds | **1.0s**（原 1.5s） | 起算底线，范围 0.5~5 |
| **FallWindowSeconds** | **5.0s**（新增） | 回落窗口，范围 0~15 |
| NoisyCooldownSeconds | — | **已移除**（无冷却） |
| GraceSeconds | — | **已移除**（由回落窗口取代） |
| NoisyRatioThreshold | 0.5 | 不变（段结束占比归属） |

**测试（NoiseDetectionTests.cs，19/19 全绿）：**
- 瞬态：普通咳嗽/喷嚏/瞬时吵闹 → 无事件（有效时长不足 1s）
- 持续：持续一般/吵闹 → 段结束各 1 次；连续 5 分钟吵闹 → 回落才记 1 次
- 回落合并：短回落（≤5s）并成一次；长回落（>5s）分开两次；反复波动只 1 次

- 配置：FallWindowSeconds 可调（合并/分开两种场景）
- 计数层：无冷却每段都计；保护期/课间不计数；StartNewClass 重置
