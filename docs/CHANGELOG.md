更新日志
====

> 版本规则：四位版本号。第 3 位 = 问题修复；第 2 位 = 新功能；第 1 位 = 重大功能更新（如适配多平台）；末位非 0 表示测试版。

1.1.1.2（测试版 · 2026-09-12）
-------------------------

> 测试版：全插件矢量图标 + 音量条体验打磨。MD5：5131E35BD2D1C43F40660B0BB416367C（EveningSelfStudyClock.cipx）

### 🧩 体验完善

*   **全插件 emoji → Lucide 矢量图标**：设置页、大屏、关于窗口里所有 emoji（🔊☔⏳⚠🎉 等）统一换成 ClassIsland 自带的 Lucide 图标字体，随 CI 字体渲染、观感统一；天气 / 音量档位 / 预警 / 计数等随数据变化的图标也按数据选字形，不再有拼 emoji 的廉价感
*   **音量条动画**：两个采样点之间由动画平滑滑动（指数逼近、无过冲），条不再一顿一顿
*   **托盘菜单「进入大屏时钟」可开关**：设置页新增开关，关闭后 CI 托盘右键菜单不再出现该入口

### 🐛 修复

*   **音量条档位显示比检测器分级错后一档（根因修复）**：条 / 文字 / 高亮全部改为由检测器分级同源推导，修复「条还停在一般、记录却已结束定性」与「条越进吵闹却显示一般」两个现象
*   **分段刻度对齐档位边界**：档位边界 25/50/75/95 → 20/40/60/80，与轨道分段刻度对齐，条走到哪一段、文字就显示哪一档

### 🔧 调整

*   **砍掉音量条强度图标**：安静时只亮一格像颗像素点，直接去掉、只保留档位文字
*   **新增「采样间隔」设置**：默认 0.2 秒（每秒 5 次），可 0.1~1.0 秒调；调大采样变稀、更省性能、更不拖调试日志和大屏时钟

1.1.0.0（正式版 · 2026-08-30）
-------------------------

> 正式版。对比上个正式版 1.0.1.0：历经 1.0.1.1~1.0.1.3 测试版迭代，V2 音量检测算法、提醒区域、预警详情弹幕、颜文字趣味提醒等功能全部收尾，本次转为正式版发布。
> MD5：3C742EF33C80EB202A3C9C309A319841（EveningSelfStudyClock.cipx）

### ✨ 新功能

*   **V2 音量检测算法**：平滑（EMA）+ 迟滞 + 持续判定，咳嗽、喷嚏等瞬态噪音不再误计数
*   **「段模式」吵闹计数**：
    *   一段噪音累计满「起算底线」（默认 1 秒，可调 0.5~5 秒）才记一次，无冷却
    *   「回落窗口」（默认 5 秒，可调 0~15 秒）内短暂安静不断段，重新吵起并成一次
    *   按段内「一般 / 吵闹」时长占比归属：吵闹占一半及以上记「吵闹」，否则记「一般」
    *   实时「正在记录」提示（一般黄 / 吵闹红）
*   **音量阈值递增联动**：安静 < 良好 < 一般 < 吵闹 必须依次递增；把安静设为 0.01，良好的可拖范围自动变为 0.01~1.00，以此类推；拖滑块或直接填数字都不会打破顺序（填小了会被自动钳回）
*   **课程进度条**（底部双色条）：上课显示本课进度、课间显示当前休息进度；已进行深色 / 未进行浅色；颜色可调
*   **HSV 颜色选择器**：背景 / 字体 / 强调色 / 进度条 / 课程信息 / 音量条文字颜色改为取色器调整（点击色块弹出完整 HSV 面板，也可直接填 hex）
*   **RMS 阈值对数滑块**：0.001~1.000，拖动滑块或直接填数字，双向联动
*   **上课初期保护可调**：上课后前 0~10 分钟不计数（默认 3 分钟，可关闭）
*   **增加提醒功能**：
    *   左上角提醒面板：天气 / 天气预警 / 倒计时 / 文本 / 降雨提醒，跟随 CI 组件自动显示，可分别开关
    *   降雨提醒：由 CI 分钟级 / 逐小时降水数据推算「X小时内当前地区有降雨」，距离下雨 6 小时内附「记得带伞哦」
    *   预警列表按等级着色（蓝 / 黄 / 橙 / 红）
*   **预警详情弹幕**：鼠标悬停预警列表中的某条，顶部即以弹幕形式横向滚动显示该条预警详情全文；移开鼠标收起；悬停另一条自动切换，无需先收起旧的
    *   弹幕位于屏幕正上方，与主提醒 / 日期同一行；文字从最右侧进场、向左循环滚动，不占满显示框、不闪全文
    *   弹幕宽度随同排内容长度自适应
*   **提醒自动合并为同行**：
    *   天气固定第一行主位，与弹幕同行
    *   与天气合并优先级：降雨提醒 > 倒计时 > 文本，总宽不超过屏幕 1/3 才自动并入同行，放不下的留在左上提醒面板
    *   无天气时，第一行主位由倒计时顶替，再无就文本
    *   天气预警始终单开一行 / 多行
    *   颜文字（副标题）显示在主提醒的正下方
*   **颜文字趣味提醒**（小字号副标题，固定文本不轮换，设置页「提醒显示」子项可开关）：
    *   降雨：距离下雨 6 小时内显示「记得带伞哦 (ノω≦)」
    *   高温 ≥36°：天太热，多喝水 (￣△￣;)
    *   炎热 ≥33°：记得防晒 (っ'ω')ﾉ
    *   下雪 / 雨夹雪：注意保暖 (❁´ω`❁)；雾 / 霾：出门戴口罩 (´-ω-\`)
    *   低温 ≤8°：天冷多穿点 (｡>ㅅ<｡)；≤0°：冻手冻脚，注意保暖 (｡-\_-｡)
    *   周四：撑住！明天就能回家了！ (๑•̀ㅂ•́)و；每月 1 号：新的一个月，加油 (ง •̀\_•́)ง
    *   倒计时剩余 ≤30 天：冲刺啦，冲鸭 (๑•̀ㅂ•́)و✧
*   **提醒面板宽度约束**：降雨 / 文本 / 预警列表最大宽为屏幕 2/3，不再向下侵入中央时钟
*   **调试日志防护**：日志保留天数上限（默认 3 天，1~5 可调）、单文件大小上限（默认 500KB，可调至 3MB，超限自动滚动新文件）；开关处附提醒，测试完记得关闭

### 🐛 修复

*   课程事件订阅泄漏（P0）
*   原 0.0.0.1（内内内测版）加入进度条后无法全屏（任务栏残留）
*   弹幕只滚动窗口宽度就循环、最左边文字进场时被裁掉 → 用框架测量的真实文字宽度驱动滚动，从右侧进场完整循环
*   每次重开弹幕闪一下全文 → 同步平移 + 大偏移占位，等待布局就绪后再启动
*   弹幕（顶部居中）与倒计时（左上角）重叠 → 顶部同行布局 + 按实际宽度自动换行
*   降雨提醒副标题超过 6 小时仍提示带伞 → 与主标题同源计算到雨小时数，≤6 小时才提示
*   拖动时钟字号滑块时右侧 px 数字不跟随 → 字号 setter 补发数字通知

### 🔧 调整

*   颜文字副标题开关并入「提醒显示」子项，不再单独占一大类
*   「文本框」改名「文本」（对齐 CI 主界面叫法），相关说明同步
