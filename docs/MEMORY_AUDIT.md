# 内存与生命周期排查（OpenAI Codex）

本次区分了长期不可回收引用、隐藏时仍持有的大资源，以及重建时的瞬时内存峰值。没有提高 ClassIsland 看门狗阈值，也没有用周期性强制 GC 掩盖资源问题。

| 路径 | 本次处理 |
| --- | --- |
| 清晰背景、模糊及采样副本 | 清晰图保留所需分辨率；辅助光学缓冲限制约1080p，模糊结果复用为采样快照；补齐异常和取消时释放 |
| 全屏/半屏/设置变更 | 按当前尺寸校验结果，取消过期请求；跨主窗口、预览、预烘串行解码 |
| 液态玻璃块 | 总采样像素预算、后台限流及取消；关闭液态模式时释放位图与画布 |
| 隐藏、最小化、离开控件树 | 停止玻璃定时器、取消任务、释放图像/画布；恢复时按需重建 |
| 嵌入式快速设置 | 移除不用的右侧预览树，避免又烘一套背景；卸载时停预览及事件 |
| 预警弹幕、鼠标隐藏 | 暂停弹幕；鼠标隐藏复用定时器，避免每次移动创建延迟任务 |
| UI定时刷新 | 排队/执行期间最多一项；停止后旧会话回调失效并释放目标引用 |
| 热键及课程事件 | 幂等订阅、停止后拒绝迟到设置事件；初始化异常也执行退订 |
| 摄像头 | 释放进程查询句柄、拥有的枚举 COM 引用和字符串缓冲；不强制释放借入的回调报告 |
| HTTP及日志 | 既有 HTTP 请求/响应等使用范围释放；新增背景诊断日志按512KiB轮换，仅保留当前及上一份 |

同类 Linux 隔离测试中，4K 图像路径采样进程私有内存峰值约从554MiB降至275MiB；单套图像缓冲约55MiB。清晰图保持3840×2160，玻璃辅助图分辨率降低以控制内存。该数据不包含完整 ClassIsland、其他插件与 Windows GPU/驱动缓存，不能保证所有实机峰值相同。

新增 BackgroundMemory、BackdropLifecycle、UiWork、HotkeyLifetime 测试，以及已有回归检查。BackgroundMemory.log 位于插件配置目录，记录重建尺寸、内存和异常；如仍重启，请连同 ClassIsland 日志及故障时间提供。

未把所有进程常驻内存都视为泄漏：框架渲染缓存、运行时堆容量、单例设置及有限大小的预烘缓存属于需要区分的保留资源。Windows 原生摄像头及图形驱动仍需实机验证。
