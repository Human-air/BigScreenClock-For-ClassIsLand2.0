# 顶部课程信息布局方案（Codex）

依据文字描述处理顶部课程玻璃与天气、倒计时气泡重叠；未使用未收到的截图推断像素位置。

- 顶栏继续使用自动高度 Grid，天气、倒计时、日期保持原有分组。
- 课程信息置顶时，单独放到第三个 Auto 行，跨三列居中，不使用绝对坐标覆盖气泡。
- 两行之间至少留 18 DIP，覆盖玻璃向外扩展的各 6 DIP 后仍有间隔；半屏已有 RowSpacing 时不重复叠加大间距。
- 课程行底部再留 6 DIP，顶栏变高后主体区域、快速设置边界跟随布局自动更新。
- 回到底部时恢复原 Margin、列位置，并移除多余空行，避免残留顶部空白。

同时恢复设置、最小化、退出按钮原有 Padding（设置10×6，另两项12×6），移除新增的48 DIP最小尺寸；保留按下响应。时间栏仅显示 CI 选择的单个附加信息，包括 CI 的临近结束倒计时覆盖规则。

本次修复由 OpenAI Codex 编写。
