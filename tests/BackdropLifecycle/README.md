# 实际背景层生命周期回归检查

```sh
dotnet run --project tests/BackdropLifecycle/BackdropLifecycle.csproj -c Release
```

此检查直接链接生产 `BackdropLayer`、背景构建、模糊和液态玻璃代码，使用 Avalonia 11.3.17 的真实 Skia 后端与无界面窗口。生成 3840×2160 背景，验证快速全屏／半屏切换、最后尺寸请求、暂停后的位图与定时器释放、恢复、在途任务离树后的清理和可回收性。

不使用模拟位图或模拟后台任务；通过反射读取私有资源状态，验证已释放资源不会被后续布局／回调重新保留。打印进程与托管内存供比较，不把机器相关的 RSS／私有内存数值作为通过阈值。

测试中的折射区域使用固定尺寸控件，省略 ClassIsland 主界面、课程和设备服务。它能验证生产背景资源链路，但不能替代希沃、Windows 图形驱动和完整宿主应用的实机测试。
