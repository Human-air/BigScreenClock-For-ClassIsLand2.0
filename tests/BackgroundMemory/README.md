# 背景内存与像素回归检查

```sh
dotnet run --project tests/BackgroundMemory/BackgroundMemory.csproj
```

此程序直接链接生产环境的 `BackdropImageSet`、图像映射及 `StackBlur`，用真实 Skia 位图执行检查：

- 模糊辅助缓冲从 `short[]` 改为 `byte[]` 后，与改动前捕获的五组 SHA256 结果完全一致，包含最大／超限半径。
- 4K 清晰背景保持 3840×2160；光学快照与模糊副本按独立尺寸限制在约 1080p 像素预算内。
- 预先取消、共享构建门等待期间取消、取消后门的所有权；缺失和损坏文件；幂等释放。
- 反复进行 12 次 4K／半屏图像构建，检查每轮资源尺寸及释放后弱引用可回收。

程序报告图像缓冲字节数及采样的进程私有内存峰值。只对确定的缓冲上限、像素结果和对象释放作断言，避免把平台相关的 RSS／GC 时机写成脆弱阈值。它验证真实图像解码与模糊，不包含完整 ClassIsland、Windows 驱动、GPU 和液态面板布局；实机运行仍需验证。
