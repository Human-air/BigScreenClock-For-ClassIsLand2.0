# 大屏时钟 (BigScreenClock)

ClassIsland 插件 —— 自动全屏显示当前时间、教室分贝值和课程信息

本插件的功能演示视频现已上线哔哩哔哩（B 站）。在 B 站搜索：ClassIsland2.0 插件「大屏时钟」演示视频，或直接搜索BV号 BV1b7tH6EEmj，即可观看。视频详细介绍了插件的各项功能，建议使用前先观看。

## 功能

* 🕐 **全屏时钟**：精确到秒的大字体时间，适配教室大屏幕，字号可调；可「— 最小化」收进任务栏随时点回（收起 ≠ 退出，计时 / 吵闹计数全程持续）
* 🔑 **CI 托盘菜单入口**：右键任务栏 ClassIsland 托盘图标，菜单里可直接「进入大屏时钟」
* 🎤 **教室音量检测**：实时麦克风音量，五档显示（安静/良好/一般/吵闹/嘈杂）；阈值依次递增联动——把安静设为 0.01，良好的可拖范围就自动变成 0.01~1.00，依次类推，永远不会乱序；麦克风休眠后自动重连
* 📋 **课程时间**：显示当前课程名称和起止时间，与实际打铃时间对齐（支持 ClassIsland 时间偏移）；课间显示下节课程
* 📊 **吵闹统计（段模式）**：按课程分段统计「一般 / 吵闹」次数；一段噪音累计满「起算底线」才记一次，回落窗口内短暂停顿不断段，按段内一般/吵闹时长占比归属；上课初期保护可调
* 📈 **课程进度条**：上课显示本课进度、课间显示休息进度，已进行深色 / 未进行浅色
* 🎨 **HSV 颜色选择器**：背景 / 字体 / 强调色 / 进度条等颜色取色器调整
* 🔔 **提醒功能**：左上角提醒面板，天气 / 天气预警 / 倒计时 / 文本 / 降雨，跟随 ClassIsland 组件自动显示、可分别开关
* 🎞️ **预警详情弹幕**：鼠标悬停预警列表中的某条，顶部即横向滚动显示该条预警详情全文，移开收起
* 🤝 **提醒自动合并**：天气固定第一行主位，降雨 > 倒计时 > 文本 能放进屏幕 1/3 就自动并入同行，放不下的留在提醒面板；无天气时主位由倒计时顶替；颜文字显示在主提醒正下方；天气预警始终单开一行/多行
* 💬 **颜文字趣味提醒**：带伞 / 防晒 / 保暖 / 冲刺等小字号副标题，可整体开关
* 🛠️ **调试日志防护**：日志按保留天数自动清理、单文件超大小自动换新文件，开关处提醒用完关闭
* 🛡️ **防休眠/防屏保**：全屏期间阻止系统进入休眠和屏幕保护
