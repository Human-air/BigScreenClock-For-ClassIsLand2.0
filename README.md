###大屏时钟 BigScreenClock

面向教室大屏的 ClassIsland 插件。全屏显示时间、教室音量、课程信息和提醒，并按课程统计吵闹次数。

本插件的功能演示视频现已上线哔哩哔哩（B 站）。在 B 站搜索：ClassIsland2.0 插件「大屏时钟」演示视频，或直接搜索BV号 BV1b7tH6EEmj，即可观看。视频详细介绍了插件的各项功能，建议使用前先观看。

[ClassIsland2.0插件 「大屏时钟」演示视频](https://www.bilibili.com/video/BV1b7tH6EEmj/)

🕐 时钟

大字体显示当前时间，精确到秒。时钟的字号、颜色和上下位置可调。

上课显示当前课程，课间显示下节课程。课程信息可显示在底部，也可放在时钟与音量条之间并上下调整。时间点附加信息跟随 ClassIsland 的选择，可显示起止时间、已过时间、剩余时间、进度百分比或倒计时。底部进度条显示当前课程或课间的进度。

支持全屏和左右半屏。全屏时连续三击屏幕同一侧，可切到对应半屏，可见宽度可以调整。半屏时三击屏幕空白侧可恢复全屏。也可以在大屏底部打开快速设置。

可自定义壁纸，选择铺满裁切、完整显示或拉伸，并调节背景明暗和主题配色。时钟、音量条、课程信息等可以使用半透明、磨砂或液态玻璃背景。液态玻璃持续吃紧时，可以先降低折射清晰度，再切换玻璃档位。

🎤 教室音量

通过麦克风实时显示安静、良好、一般、吵闹和嘈杂五个档位。相邻档位的阈值联动，调整其中一档时，相关档位会限制在有效范围内。

可调整音量条的位置及标题的颜色，也可以关闭音量条。当前音量档位随声音变化。

📊 计数

按课程统计一般和吵闹次数。达到起算底线才记一次，回落到安静或良好的时间超过回落窗口后结算。较短的回落合并到同一段。

连续处于吵闹档达到设定时长，或最近十秒内累计处于吵闹档达到设定时长，即把本段记为吵闹。两项时长均可调整，默认分别为五秒和六秒。锁定后回到一般档，本段仍会结算为一次吵闹。

课间不计数。上课初期可开启保护并设置时长，倒计时与正在记录共用提示位置。计数字号可调。

🔔 提醒

跟随 ClassIsland 显示天气、降雨提醒、天气预警、倒计时和文本，可分别开关。能放进顶部一行的内容会自动并排显示，其余内容留在提醒区。

悬停天气预警可在顶部查看滚动详情。摄像头被占用时可显示提示，设备可在设置中选择。安装并启用地震预警插件后，大屏也可以显示地震预警。

📨 飞书推送

可在一段噪音结算时向飞书群发送文字卡片。可以只推送吵闹，也可以同时推送一般和吵闹。课间和上课初期保护内的噪音不推送。还可以启用进入和退出大屏时钟通知，退出卡片会附上本次时长与计数。

在飞书群设置中添加自定义机器人，把 Webhook 地址填入插件设置。开启了签名校验时一并填写密钥。设置页提供测试发送、同等级冷却、请求超时和直连选项。

🛠️ 维护与测试

本项目由在校学生利用课余时间维护。维护者在校期间若仅能通过手机访问仓库，可能借助 OpenAI Codex 分析和回复 Issue、编写修复代码及构建开发包，相关回复和发布说明会明确注明。实机测试主要在教室的希沃设备上进行。反馈时请尽量附上插件版本、复现步骤和相关日志。

设置迁移自 1.2.3.0 起支持。两台电脑均需达到该版本。导出 JSON 文件并在另一台电脑导入，重启 ClassIsland 后生效。壁纸文件、设备选择和飞书凭据保留在本机。
