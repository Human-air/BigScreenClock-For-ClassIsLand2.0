# 大屏时钟 (BigScreenClock)

ClassIsland 插件 —— 自动全屏显示当前时间、教室分贝值和课程信息

本插件的功能演示视频现已上线哔哩哔哩（B 站）。在 B 站搜索：ClassIsland2.0 插件「大屏时钟」演示视频，或直接搜索BV号 BV1b7tH6EEmj，即可观看。视频详细介绍了插件的各项功能，建议使用前先观看。

## 功能

* 🕐 **全屏时钟**：精确到秒的大字体时间，适配教室大屏幕，字号可调；可「— 最小化」收进任务栏随时点回
* 💤 **最小化自动暂停**：最小化超过设定时间（1~30 分钟）后停止计时、音量检测、摄像头检测与防休眠；窗口不关、任务栏入口保留，点回即恢复（可关闭）
* 🔑 **CI 托盘菜单入口**：右键任务栏 ClassIsland 托盘图标，菜单里可直接「进入大屏时钟」
* 🎤 **教室音量检测**：实时麦克风音量，五档显示（安静/良好/一般/吵闹/嘈杂）；阈值依次递增联动——把安静设为 0.01，良好的可拖范围就自动变成 0.01~1.00，依次类推，永远不会乱序；麦克风休眠后自动重连
* 📋 **课程时间**：显示当前课程名称和起止时间，与实际打铃时间对齐（支持 ClassIsland 时间偏移）；课间显示下节课程
* 📊 **吵闹统计（段模式）**：按课程分段统计「一般 / 吵闹」次数；一段噪音累计满「起算底线」才记一次，回落窗口内短暂停顿不断段，按段内一般/吵闹时长占比归属；上课初期保护可调
* 📈 **课程进度条**：上课显示本课进度、课间显示休息进度，已进行深色 / 未进行浅色
* 🎨 **自定义背景图**：可选一张图片当整屏背景（副本存进插件配置目录，原图挪走/删掉都不影响），填充方式支持铺满裁切 / 完整显示 / 拉伸，「背景明暗」可把整张背景压暗或提亮；开了背景后配色由「背景主题」说了算——自动（跟着背景图）/ 暗底白字 / 亮底黑字
* 🧊 **组件玻璃底**：时钟、提醒、日期、音量条等每个独立组件各垫一块圆角玻璃，四档可选——关闭 / 半透明 / 磨砂 / 真•◯◯玻璃。真•◯◯玻璃是贴边的画面被推弯的真折射，带一圈镜边高光，折射强度与雾面浓度可调（雾面浓度给文字可读性兜底）。地震提醒块不垫玻璃
* 🎨 **HSV 颜色选择器**：背景 / 字体 / 强调色 / 进度条等颜色取色器调整
* 🔔 **提醒功能**：左上角提醒面板，天气 / 天气预警 / 倒计时 / 文本 / 降雨，跟随 ClassIsland 组件自动显示、可分别开关
* 🎞️ **预警详情弹幕**：鼠标悬停预警列表中的某条，顶部即横向滚动显示该条预警详情全文，移开收起
* 🎥 **摄像头占用提醒**：摄像头被程序占用时（相机、通话、网页调用都算）在预警行显示「摄像头使用中」，悬停详情写明是哪个程序在用；要监控哪几个摄像头在设置里勾
* 🤝 **提醒自动合并**：天气固定第一行主位，降雨 > 倒计时 > 文本 能放进屏幕 1/3 就自动并入同行，放不下的留在提醒面板；无天气时主位由倒计时顶替；颜文字显示在主提醒正下方；天气预警始终单开一行/多行
* 💬 **颜文字趣味提醒**：带伞 / 防晒 / 保暖 / 冲刺等小字号副标题，可整体开关
* 🛠️ **调试日志防护**：日志按保留天数自动清理、单文件超大小自动换新文件，开关处提醒用完关闭
* 🛡️ **防休眠**：全屏期间阻止系统与显示器进入睡眠（不挡屏保，屏保由系统策略决定）
* 📨 **飞书推送**：检测到教室吵闹（可选「一般」级）、进入 / 退出大屏时钟时，自动发消息到飞书群；支持签名校验、同级冷却防刷屏、请求超时可调、可选直连
* 📷 **自动抓拍**：每次推送自动抓拍教室现场照片（可选摄像头、分辨率），照片同步存本地；未配置摄像头或抓拍失败不影响文字推送
* 🎙️ **吵闹录音**：噪音段结算后自动录一段现场音频（10~60 秒可调，默认 15 秒），先存本地再上传发到飞书群，卡片上标注录音状态
* 📣 **快捷键打小报告**：全局热键（默认 `Ctrl+Alt+R`，设置页可改）随时一键举报——强制抓拍 → 橙色报告卡片 → 录 10 秒现场音频 → 发到群里；10 秒冷却防误触

## 飞书推送与抓拍配置

### 1. 群机器人（文字消息，必配）

飞书群 → 设置 → 群机器人 → 添加机器人 → **自定义机器人**，复制 Webhook 地址（`https://open.feishu.cn/open-apis/bot/v2/hook/xxx`）填进插件设置页。如开启「签名校验」，把密钥一并填入。

### 2. 自建应用（照片 / 录音发到群里，可选）

飞书自定义机器人**不能直接发图片，也不能发音频文件**，这类附件要出现在群里必须走额外的自建应用：

1. 打开 [飞书开放平台](https://open.feishu.cn) → 开发者后台 → **创建企业自建应用**
2. 「凭证与基础信息」页复制 **App ID**（`cli_xxx`）与 **App Secret**
3. 「权限管理」按需开通以下权限：

   | 权限 | 用途 | 照片 | 录音 |
   |---|---|---|---|
   | `im:resource` | 获取与上传图片或文件资源 | 必需 | 必需 |
   | `im:message` | 以应用身份发消息（`im/v1/messages`） | — | 必需 |
   | `im:chat` | 读取群列表，用于一键查询 `chat_id` | — | 必需 |

4. **「版本管理与发布」→ 创建版本并发布**——权限不发布不生效，这是最容易漏的一步
5. 把 App ID / App Secret 填进插件设置页「📷 抓拍」分区

> 不配置自建应用也能用：文字消息照常发送，照片只存本地（`图片\大屏时钟抓拍\日期\时间.jpg`），录音只存本地（`音乐\大屏时钟录音\日期\`），卡片上会注明已存本地。

### 3. 录音发到群里（需要 `chat_id`）

机器人 Webhook 没有「发文件」能力，录音走自建应用的 `im/v1/files` + `im/v1/messages`，因此必须先知道往哪个群发：

1. 在飞书群里 → 设置 → 群机器人 → 添加机器人 → 选择你创建的**自建应用**（不是自定义机器人），把它拉进群
2. 插件设置页 →「🎙 现场录音」分区 → 点 **🔍 查询群列表**
3. 下拉框里选中目标群，`chat_id` 自动保存（形如 `oc_xxxxxxxx`）

> 未选群时录音只存本地并在卡片上标注「录音已存本地」；选了群但权限/发布没配好时，卡片会显示飞书返回的具体错误码。

### 4. 快捷键打小报告

* 默认热键 `Ctrl+Alt+R`，在设置页「📣 快捷键打小报告」里可改为任意 `Ctrl / Alt / Shift / Win` + 字母 / 数字 / `F1~F24` 组合
* 热键为**系统级全局**，不要求大屏时钟窗口在前台；触发后 10 秒冷却
* 执行顺序：强制抓拍（不受「推送时抓拍」开关限制）→ 发橙色报告卡片 → 录 10 秒音频 → 上传发群
* 设置页有 **🚨 测试** 按钮，可立即验证照片 + 录音 + 群发送整条链路（忽略冷却）
* 若热键被其它软件占用，系统注册会失败且不会弹提示（表现为按下无反应），换一个组合即可

### 5. 行为说明

* **触发时机**：噪音段结算为「一般 / 吵闹」（可只推「吵闹」）、进入大屏时钟、退出大屏时钟（附本次会话时长与一般/吵闹累计）
* **录音行为**：噪音卡片先发出（标注「正在录制 N 秒现场音频…」），录音在后台进行，完成后以「文字说明 + WAV 文件」两条消息补发到群；本地同时留档 `音乐\大屏时钟录音\日期\HHmmss.wav`。录音与音量检测用独立采集实例，互不干扰
* **防刷屏**：同一等级 30 秒冷却（0~600 秒可调），卡片为交互式消息（interactive），文字送达后照片上传失败会自动降级为纯文字并在卡片上注明原因
* **发送失败排查**：设置页「📨 测试发送」会显示飞书返回的具体错误码；浏览器能打开 Webhook 但插件超时时，勾选「直连（不走系统代理）」或调大超时时间（默认 30 秒）
